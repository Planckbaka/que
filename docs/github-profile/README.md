## How I approach engineering

- Start with the behavior and failure modes before choosing an abstraction.
- Keep concurrency, resource ownership, and cancellation explicit.
- Measure representative workloads before making performance claims.
- Prefer small interfaces, readable code, and tests around meaningful boundaries.
- Write down the tradeoffs so the next change is easier to reason about.
