In the old counting rhyme, seeing a single magpie is an omen of sorrow. In this unmasked example, a query compares itself with every key. Causal attention restricts that visibility to allowed earlier positions. The witness metaphor illustrates weighting; it is not a claim about factual reliability.

## The Lineup Procedure

A query walks into the room. Three keys stand against the wall. The procedure is always the same three steps:

1. **Resemblance.** Score each key against the query with a dot product — a measure of compatibility in the projected space. Learned query and key projections need not be the same.
2. **The scale correction.** Divide by the square root of the key dimension. Without it, high-dimensional dot products grow in variance with the dimension, and the softmax that follows can become overly concentrated. One witness would be believed completely; the rest dismissed before speaking. The scale keeps the jury *deliberating*.
3. **Cross-examination.** Softmax the scores into a distribution that sums to one, then blend the value vectors under it.

## Exhibit 018-B

The whole procedure fits in six lines. Filed as evidence:

```python
import numpy as np

def scaled_dot_attention(
    q: np.ndarray, k: np.ndarray, v: np.ndarray
) -> tuple[np.ndarray, np.ndarray]:
    scores = (q @ k.T) / np.sqrt(k.shape[-1])   # resemblance, scaled
    weights = np.exp(scores - scores.max(-1, keepdims=True))
    weights = weights / weights.sum(-1, keepdims=True)  # cross-examination
    return weights @ v, weights

q = np.array([[1.0, 0.0]])
k = np.array([[1.0, 0.0], [0.0, 1.0], [0.9, 0.1]])
v = np.array([[10.0], [20.0], [30.0]])
blend, witness = scaled_dot_attention(q, k, v)
print(witness.round(3))   # [[0.412 0.203 0.384]]
print(blend.round(2))     # [[19.72]]
```

The weights are approximately 0.412, 0.203, and 0.384. The result, 19.72, includes all three values; it is not the value of the best-matching key. The first and third keys receive similar weights because their scaled scores are close.

## Why Nobody Stays Silent

For finite unmasked scores in exact arithmetic, softmax assigns positive weights. That does not guarantee a useful gradient for every score: saturation, upstream derivatives, masking, and finite-precision underflow matter. A sharply peaked distribution can make learning difficult.

Without dropout, the weighted sum lies in the convex hull of the value vectors. This observation applies to this head's aggregation, not the full network after projections and residual connections. It does not show that hallucinations originate only in feed-forward blocks. Attention weights are not factual confidence scores.

Scale the scores, normalize over keys, and blend the values. The numerical result is a weighted average, not a verdict about truth. Continue with [Attention, From Tensor Shapes to KV Cache](/files/llm-attention-from-shapes-to-kv-cache) for causal masking and inference memory.
